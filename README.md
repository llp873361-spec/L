# 粉色星空

粉色星空里有一个黑洞，点进去是一片粉色的海，海里漂着几百个"世界小球"，每个小球里是一个小世界。全部画面都是 Three.js 加着色器现场算出来的，没有外部图片、模型和音频。

## 本地运行

ES module 不能用 `file://` 直接打开，在项目目录下起个静态服务器：

```
python -m http.server 8000
```

然后打开 http://localhost:8000 。

地址后面加 `?fps`，左上角会显示帧率、进入当前层之后 30 秒的平均帧率和当前像素比。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面、importmap（three@0.186.1）、不支持 WebGL2 时的静态星空 |
| `main.js` | 层级切换、穿越动画、后处理、到访记录 |
| `palette.js` | 8 个色板颜色，以及着色器共用的颜色换算和噪声 |
| `sky.js` | 星空层（镜夜世界会复用这里的 `build`） |
| `ocean.js` | 海洋层 |
| `worlds/city.js` | 灯城：山坡上的童话小城，刚入夜 |
| `worlds/flower.js` | 花潮：清晨薄雾里的花海 |
| `worlds/rain.js` | 雨汀：雨里的浅水草甸和芦苇小岛 |
| `worlds/desert.js` | 沙昼：白天的沙海，站在一座巨型沙丘上俯看连绵起伏的圆沙丘 |
| `worlds/mirror.js` | 镜夜：站在湖中央的一方小木台上，天上和水里各有一个黑洞，分不清哪边是天 |

## 各个世界里能做什么

- 灯城：点任意一扇窗，它先灭再亮，周围的窗户像水波一样一圈圈跟着响应。
- 花潮：按住鼠标（手机上按住屏幕），风会慢慢变大，花浪更宽更密、吹落的花瓣更多；松开后风慢慢平息。
- 雨汀：点水面，落下一颗大水滴，把周围的小涟漪推开；偶尔会有一道粉色闪电。
- 沙昼：进去先是一片白光慢慢退开；左右移动鼠标，太阳会跟着转，沙丘的影子跟着滑；远处地平线上有热浪扭动。
- 镜夜：进去时天是暗的，星星一颗一颗亮起来，天上和湖里同时出现；偶尔有一阵风从湖面扫过，倒影晃一晃又静下来。点水里那个黑洞的倒影，镜头会一头扎进去，穿过去就回到了最开始的星空。
- 每个世界左下角都有"回到海洋"按钮，按 Esc 也可以。回到海洋时镜头会停在刚才点的那颗小球前面。

同一颗小球每次进去看到的世界完全一样；同一类的不同小球：
- 灯城的山形、塔的位置、余晖方向不同。
- 花潮的太阳方位、风向、小径走向、花色和花型比例不同。
- 雨汀的云缝方向、小岛位置和大小、芦苇丛的分布不同。
- 沙昼的风向、太阳方位和高度、沙丘的间距、高矮和排布不同。
- 镜夜的星云和星星分布、木台朝向和木板纹理、萤火虫的位置和闪烁节奏不同。

## 颜色是怎么守住色板的

- 所有着色器都按"最终显示色"来算颜色，只在色板颜色之间插值，最后调用 `dsp()` 换算成线性值。`dsp()` 是 three.js 里 ACESFilmic 的精确反函数，所以一个纯色板色经过色调映射后显示出来还是它自己。
- 后处理最后一步把每个像素投影到"色板两两之间的 28 条线段"上，距离按亮度加权。叠加、雾、辉光、抗锯齿混出来的颜色都会被拉回色板线段上。
- 辉光只取显示亮度落在樱花粉、粉白这一段的像素，半分辨率计算（手机四分之一）。
